# Voice Task Bot
Telegram-бот: голосовые и кружочки → расшифровка → список задач (Google Gemini).

Переменные окружения: `BOT_TOKEN`, `GEMINI_API_KEY`, `ALLOWED_USER_IDS` (твой Telegram ID, чтобы ботом не пользовались чужие).
Локально: `pip install -r requirements.txt && BOT_TOKEN=... GEMINI_API_KEY=... python bot.py`
